# 90% Online Delivery — Effective Practices (Top Unis, 2026-09-06)

Research for Cakrawala Kelas Profesional evening courses (BI/WAD/SDLC) when 90% online, 10% synchronous.
Sources: MIT OEIT Online Course Design Guide (MIT-OEIT + NMC), Harvard Derek Bok Center — Best Practices Residential/Blended/Online, Martin et al. OCDE rubric (5 cats, 38 items), Young (2026) ECHO Framework (Community of Inquiry + TPACK, OJDLA), Martin-Polly-Ritzhaupt (2020) Bichronous Learning (EDUCAUSE Review), Frontiers systematic review (collaborative/case/simulation), Quality Matters Higher Ed Rubric 7th ed.

## Why this matters for Cakrawala
- Working professionals 19:00+, mixed roles, no shared baseline — fully async without design hurts completion (Xu & Jaggars). Need scaffolded self-regulation.
- Current no-homework constraint (all artefacts in-session, due before leaving room) breaks at 90% online — must recast as bounded async window.
- Real slots differ: BI 105 min (18:15-20:00), WAD 120 min (20:00-22:00), SDLC 90+90 min (18:30-21:30 = 2 sesi/meet) — sync time is scarce, so reserve it for what async cannot do.

## Core model: Bichronous (not fully async)
- 90% async for content consumption, 10% sync for high-value interaction (debate, defense, red-team, scope negotiation).
- COIL case (China/Algeria/Portugal): 3 sync touchpoints (opening, mid check, showcase) reduced logistics, deepened reflection.
- Cakrawala mapping: keep sync for Sesi 1 (orientation), Sesi 8 (UTS + scope cut signing), Sesi 15-16 (capstone defense/UAS). Other sesi: async video chunks + async board + 30-min live clinic.

## Design rules distilled
1. **Chunk + roadmap.** Harvard: break prerecorded into 3-5 min segments with explicit roadmap per module. MIT: online dev takes MORE time — rich media needed because no face-to-face repair. Cakrawala rule ≤12 min talk without interaction → async: ≤6-8 min video + embedded poll/predict-then-reveal before next chunk.
2. **Organization is retention.** OCDE learner-content interaction strongest predictor of satisfaction. If navigation unclear, retention collapses. Don't port face-to-face to LMS. Need per-module: measurable objectives, where to find resources, how to interact, what to submit, deadline.
3. **Community of Inquiry (ECHO).** Social + cognitive + teaching presence must be designed. Online retention lower than residential. Tactics: 2-min instructor weekly video + PDF slides (consistent format), buzz groups via breakout (Harvard) → async via Google Docs/Miro board, gallery walk → async board with peer comments.
4. **Interaction planned, not incidental.** Harvard broadens lean-forward: polls, cold-call with warning, buzz groups, collaborative docs. Frontiers: collaborative learning + case studies + simulations (virtual labs, gamification). Use role-diverse groups (analyst/ops/QA/PM) as teaching resource — prompt per role async.
5. **Assessment aligned & varied.** OCDE: assessment tied to outcomes, varied by Bloom level. Avoid 13× "Tugas praktik". Use project-based + practical + quiz. Transparent rubrics (Cakrawala already has 50/20/15/15 functional/quality/docs/defense) — keep.
6. **Student support.** ECHO/QM: tech orientation, catch-up path. Cakrawala "If you missed this week" 15-min becomes async catch-up module.
