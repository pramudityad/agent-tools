# Artifact Classification

Distinguish between materials distributed to students and instructor-only demo/teaching artifacts to prevent distribution confusion (e.g., student zip vs projector demo).

## 1. Student-Facing Artifacts (Distributable)

- **Task Starter:** `starter/` (e.g., `bis-cakrawala-starter/`).
- **Student Reference:** Task-specific docs provided in student repos (e.g., `app-pagination.js`).
- **Guidelines:** Files in `starter/` or reference zips intended for student modification or reading.

## 2. Instructor-Facing Artifacts (Internal/Proyektor)

- **Visual Deck:** `Sesi NN - Slides.html` / `Sesi NN - Slides.pdf`.
- **Live Demo Scripts:** `Sesi NN - Demo.html` (interaktif untuk proyektor).
- **Delivery Scripts:** `references/instructor-delivery-script.md` (naskah pengampu).

**Guidelines:** Do NOT include these in student zip files. If an artifact is mentioned in a README distributed to students, ensure it is either included in the student distribution OR clarify that it is an instructor-only demo file NOT provided to students.
