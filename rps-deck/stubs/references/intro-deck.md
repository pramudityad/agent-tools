# The intro deck (`00 Intro Dosen`) — separate artifact, not a Sesi deck

A lecturer-introduction deck (`00 Intro Dosen - Slides.html` → `.pdf`) is its own artifact,
hand-built from scratch — **not** through the six steps above and not a `Sesi NN` deck (user
correction: *"this separate slide only for introduction. i already have slide for
teaching"*). No RPS row governs it. Course-neutral — serves every course from the same
lecturer — and lives at the course-set's own project root, not inside one course's folder.

Content shape: cover → siapa saya → timeline perjalanan → what-I-build → contact → closing.

- Facts come from the lecturer's own CV/career notes, which are typically incomplete for
  older roles — cross-check other sources and ask the user before building a career history.
  Never invent numbers on an intro slide.
- Deck language is the lecturer's choice for this one deck specifically and may differ from
  the teaching decks' language (a validated build used English for the intro deck while
  every teaching deck stayed Indonesian) — ask rather than assume it follows the course
  language.
- Contact block: institutional email as the primary channel, a stated reply SLA, and a
  flexible form of address.

The old Playwright print recipe was retired with the HTML decks (ADR 0009); export through
the Slidev workspace instead (`slidev.md`).
