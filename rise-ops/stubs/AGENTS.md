  portal: attendance, berita acara, session open/close, pre-class briefing, attendance
  register. Read `CONTEXT.md` first. It never writes grades — nilai akhir is SEVIMA SIAKAD,
  a separate system (ADR 0001). Sibling to `rps-deck`, which builds the sesi this one runs.
